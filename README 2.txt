GITHUB PAGES:
1. Buat repository baru di GitHub, misalnya: happy-girlfriend-day
2. Upload SELURUH isi folder ini (index.html, style.css, script.js, README.txt, dan folder assets).
3. Masuk Settings > Pages.
4. Pada Build and deployment pilih Deploy from a branch.
5. Pilih branch main dan folder / (root), lalu Save.
6. Setelah selesai, GitHub akan memberikan URL GitHub Pages untuk dibagikan.
